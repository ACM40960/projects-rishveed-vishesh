# Expected Goals (xG) Modelling in Football

A calibrated Expected Goals model built on StatsBomb open data, developed as a
**mathematical modelling** project (module ACM 40960). The project treats xG as a
mathematical model, not just a prediction task: shot geometry is derived from
first principles, the baseline fit is framed as a maximum likelihood optimisation
problem, and the model is extended to match outcomes (Monte Carlo simulation),
uncertainty (Bayesian), and behaviour (sensitivity analysis).

## Data scope

StatsBomb's open data only fully covers the **2015/16** season for the major
leagues, so this project combines the four full 2015/16 seasons of **La Liga,
Premier League, Serie A, and Ligue 1** into one dataset (~1,500 matches). After
removing penalties this gives **37,488 shots** (3,569 goals, 9.5% conversion).
Other seasons in the open release are partial, player-specific subsets and are
excluded to avoid bias. Data is accessed through the `statsbombpy` library.

(and is downloaded from StatsBomb). It is included in this download for
convenience so you can run later steps without re-downloading.

## Setup

```bash
git clone <your-repo-url>
cd xg-modelling
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Running the pipeline

Run everything at once (the first two steps download data, allow a few minutes):

```bash
python run_all.py
```

Or run the scripts individually, in order, from the repo root:

| # | Script | Produces |
|---|--------|----------|
| 01 | `scripts/01_get_fixtures.py` | real match results (`data/fixtures.csv`) |
| 02 | `scripts/02_extract_clean.py` | all shots (`data/shots_2015_16_top4.csv`) |
| 03 | `scripts/03_geometry.py` | distance + angle features, geometry figures |
| 04 | `scripts/04_baseline_logit.py` (+`04b`) | baseline logistic model + figures |
| 05 | `scripts/05_baseline_eval.py` | AUC, Brier, calibration |
| 06 | `scripts/06_encode_features.py` (+`06b`) | encoded features (`data/model_features.csv`) |
| 07 | `scripts/07_enhanced_logit.py` (+`07b`) | enhanced logistic model |
| 08 | `scripts/08_random_forest.py` (+`08b`) | Random Forest |
| 09 | `scripts/09_xgboost.py` (+`09b`) | XGBoost |
| 10 | `scripts/10_comparison.py` | model comparison table + figure |
| 11 | `scripts/11_calibration.py` | calibration-correction check |
| 12 | `scripts/12_applied_outputs.py` | shot map, xG surface, finishing table |
| 13 | `scripts/13_match_simulation.py` (+`13b`) | Monte Carlo xG league tables |
| 14 | `scripts/14_bayesian_uq.py` | Bayesian uncertainty (Python demo) |
| 15 | `scripts/15_sensitivity.py` | local + global (Sobol) sensitivity |

Steps depend on earlier ones, so keep the order.

## Model progression

1. **Baseline logistic regression** on distance + angle — interpretable, framed as maximum likelihood.
2. **Enhanced logistic regression** adding body part, technique, play pattern, pressure, first-time.
3. **Random Forest** and **XGBoost** — flexibility vs interpretability.
4. **Evaluation throughout** — AUC-ROC, Brier score, calibration (ECE), benchmarked against StatsBomb's own xG.
5. **Applied outputs** — pitch xG surfaces, shot maps, player finishing table (goals − xG).
6. **Extensions** — Monte Carlo match simulation (Poisson-binomial), Bayesian uncertainty (Stan), sensitivity analysis (Sobol indices).

Headline result: the enhanced logistic model, Random Forest, and XGBoost tie
(~0.78 AUC), all well calibrated; the gap to StatsBomb (~0.82) is due to missing
defender/goalkeeper position data, not model choice.
